# FZ3B 本地语音转写

解压后双击 FZ3B-Transcribe.cmd。将 UGREEN 摄像头插到 Windows 主机的 USB 口，网线直连 FZ3B。客户端预填板卡地址 169.254.220.254，使用板卡现有 SSH 账户，密码仅在该次客户端进程内使用。

选择「麦克风 (UGREEN Camera 2K)」并开始录音。界面会显示音量、时长和板卡返回的临时原稿。点击「停止录音」后，客户端发送剩余音频，等待板卡确认收到的样本数并返回最终原稿。可以复制文字，也可以从「打开保存位置」找到 WAV 和 TXT。

「打开 WAV」可重新转写已有录音。连接出错时，客户端会在主机继续录音，停止后可打开保存的 WAV 再提交。

默认使用「智能分段 · 中英混合」。短暂停顿后恢复说话时，客户端重新建立识别上下文，并为新段保留起句前的短缓冲。可从「转写模式」切换到连续识别或只在较长停顿后分段。

客户端连接已部署的 FZ3B INT8 流式入口。板卡重启后的首次转写会等待语音服务装载并校验。声音从主机发送到直连 FZ3B，摄像头的画面留在主机。

带 Qwen 的版本会在原稿保存后启动 Windows 本地整理。通过「查看整理稿」对照两份文字，可以取消整理，也可以关闭自动整理后手动发起。整理稿使用单独的 TXT 文件。
